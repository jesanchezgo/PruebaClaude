# AGENTS.md

Angular 22 app in `angular-app/` (standalone components, CSS, no SSR). Run all commands from that folder.

## Commands
- `npm install`
- `npm start` — dev server (`ng serve`)
- `npm run build` — production build to `dist/`
- `npm test` — unit tests (`ng test`)

## Notes
- Requires Node >= 22.22.3 (or 24.15+); older Node makes the Angular CLI refuse to run.
- Style: 2 spaces, single quotes in TS (see `.editorconfig`).
- Work on `develop`; `main` is the base branch.
